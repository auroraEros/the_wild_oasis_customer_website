
## The Wild Oasis - Customer App

![The Wild Oasis Screenshot](/public/screenshot.png)

This is the customer version of the hotel management web app, where users can:

- View all available cabins with descriptions and images.
- Book a cabin based on available dates and select the number of guests.
- Sign in with Google to manage bookings.
- View your booked cabins, edit them, or cancel if needed.
- Update your profile information.
- Fully responsive on all devices.

---

### 🛠️ Technologies Used

- **Next.js** (App Router)
- **Tailwind CSS**
- **Supabase**
- **NextAuth.js** (Google sign-in)
- **Date-fns** for date handling

### 🚀 Getting Started

To run this project locally:

```bash
git clone https://github.com/auroraEros/wild-oasis-customer.git
cd wild-oasis-customer
npm install
```

Create a `.env.local` file and configure Supabase & NextAuth variables.

Run the app:

```bash
npm run dev
```
